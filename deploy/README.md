# 키오스크 배포 가이드 (GMKtec N100 + LG 스탠바이미 2)

이 프로젝트를 GMKtec N100 미니PC(Windows)에 설치하고, HDMI로 연결한 LG 스탠바이미 2를
세로 모드 터치 키오스크로 띄우기 위한 설정 순서입니다.

## 0. 사전 확인 (필수)

- 스탠바이미 2와 미니PC를 **HDMI(영상) + USB(터치 패스스루)** 두 케이블로 모두 연결하세요.
  USB 연결이 빠지면 화면은 나오지만 터치가 동작하지 않습니다.
- Windows 장치관리자에서 "사람 인터페이스 장치(HID)" 아래에 터치스크린 장치가 잡히는지 확인하세요.

## 1. BIOS 설정 — 정전 후 자동 전원 켜짐

부팅 시 `Del` 또는 `F7`로 BIOS 진입 → Advanced 메뉴에서
**"AC Back" / "Restore on AC Power Loss" / "Power On After AC Loss"** 항목을
**Power On**으로 설정합니다. 매장에서 정전이 있어도 사람이 전원 버튼을 누르지 않아도
자동으로 재부팅되게 하기 위함입니다.

## 2. Windows 설정

1. **디스플레이 방향 세로로 회전**
   설정 → 시스템 → 디스플레이 → 디스플레이 방향 → **세로**
   (스탠드로 돌린 방향에 따라 "세로" 대신 "세로(대칭 이동)"가 맞을 수 있습니다. 실제로 보면서 맞는 쪽으로 선택하세요.)
2. **화면 꺼짐/절전 끄기**
   설정 → 시스템 → 전원 및 절전 → 화면: **안 함**, 절전: **안 함**
3. **자동 로그인 설정**
   `Win + R` → `netplwiz` 실행 → 키오스크 전용 계정 선택 →
   "사용자가 이 컴퓨터를 사용하려면 사용자 이름과 암호를 입력해야 함" 체크 해제.
   (재부팅 시 로그인 화면에서 멈추지 않고 바로 바탕화면까지 가야 자동 실행이 이어집니다.)
4. **Google Chrome 설치** (안정 버전, 기본 경로에 설치)

## 3. 프로젝트 파일 배치

이 저장소 전체를 미니PC의 아무 폴더에 복사합니다. 예:

```
C:\kiosk\
├─ index.html
├─ kiosk\
├─ src\
├─ asset\
└─ deploy\
     ├─ launch-kiosk.bat
     └─ run-hidden.vbs
```

`deploy\launch-kiosk.bat` 은 자기 위치 기준 **한 단계 위 폴더의 index.html**을 자동으로 찾으므로
폴더 이름(`C:\kiosk`)은 달라도 상관없습니다. `deploy` 폴더가 프로젝트 루트 바로 아래에만 있으면 됩니다.

## 4. 부팅 시 자동 실행 등록

`Win + R` → `shell:startup` 입력 → 열리는 폴더에
`deploy\run-hidden.vbs` 의 **바로가기**를 만들어 넣습니다.

(참고: 이 vbs는 검은 cmd 창 없이 `launch-kiosk.bat`을 백그라운드로 실행하고,
`launch-kiosk.bat`은 Chrome이 죽거나 실수로 종료돼도 자동으로 다시 켜주는 워치독 루프입니다.)

## 5. 최종 테스트

1. 미니PC를 재부팅합니다.
2. 로그인 화면 없이 바로 바탕화면으로 진입 → 잠시 후 Chrome이 전체화면(주소창 없음)으로 자동 실행되는지 확인.
3. 스탠바이미 화면을 손가락으로 눌러 매장/포장 버튼이 정상 반응하는지 확인.
4. 작업 관리자에서 `chrome.exe` 를 강제 종료해보고, 몇 초 안에 자동으로 재실행되는지 확인.
5. 콘센트를 뽑았다가 다시 꽂아 정전 상황을 재현하고, 사람 개입 없이 처음부터 자동 복구되는지 확인.

## 로컬에서 미리 보기(개발 중 확인용)

각 화면이 `src/screens/*.html` 실제 페이지이고 화면 이동도 전부 일반 링크(`<a href>`)라서,
`fetch`/CORS 문제 없이 `index.html`을 그냥 더블클릭해서 열어도 바로 확인할 수 있습니다.
로컬 서버나 특수 플래그가 필요 없습니다.

## 종료/유지보수 방법

- 키오스크를 잠시 끄려면: 작업 관리자(`Ctrl+Shift+Esc`)에서 `chrome.exe`와 `cmd.exe`(launch-kiosk.bat 실행 창)를 모두 종료하세요.
  `chrome.exe`만 끄면 워치독이 바로 재실행시킵니다.
- 코드를 수정했다면 `C:\kiosk` 폴더의 파일을 갱신한 뒤 Chrome을 껐다 켜면(워치독이 재실행) 새 버전이 반영됩니다.
- 원격 유지보수가 필요하면 Windows 원격 데스크톱(RDP) 또는 AnyDesk 등을 함께 설치해두는 것을 권장합니다.
